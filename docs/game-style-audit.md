# 인게임 스타일 대조 기록

기존 홈페이지의 여백·아트 배치는 유지하며 실제 게임에 맞춰 타이포그래피·로고·강조색·패널을 조정했습니다.

## 실제 참조

- 게임 `src/ui/fonts.ts`: NEXON Kart 500 / 700 / 800, 일본어 FG Sans JP 폴백 순서.
- 게임 `src/ui/theme.ts`: 바탕 #1a1d21, 패널 #24282e, 경계 #3a404a, 본문 #f2f0ec, 금빛 #d8b978, 출격 #d85f34.
- 게임 `src/ui/holo.ts`, `src/ui/Button.ts`: 평평한 면·기울어진 버튼·잘린 모서리·겹침으로 만드는 깊이.
- 게임 `public/sprites/ui/titlename.webp`: 원본 로고의 투명 여백을 제거해 `for-garden-logo.webp`로 보관. 글자 모양과 색은 다시 만들지 않았습니다.

## 플레이 화면 확인

테스트 모드 빌드를 실제 Chromium으로 실행하고 타이틀 → 로비 → 렐릭 도감 → 연구소를 확인했습니다. 고고학 탭은 해당 시작 저장에서 잠겨 있어 캡처 대상에서 제외했습니다. 별도 실행에서 로비 → 지도 → 편성 → 전투로 이동했고 실제 fight 상태를 확인했습니다. 게임 코드나 테스트 파일은 수정하지 않았습니다.

확보한 7장: `public/assets/screenshots/{title,lobby,relics,lab,map,party,battle}.webp`. 홈페이지에는 실제 캡처임을 명시하고 확대 보기와 개발 중 고지를 제공합니다. 개발용 초기 저장을 사용하므로 재화·보유 렐릭·UI는 출시 상태를 보장하지 않습니다.

타이틀은 추가 캡처에서 원본 영상의 첫 프레임을 정지해 토리카가 눈을 뜬 장면으로 교체했습니다. 얼굴을 편집하거나 다른 이미지로 합성하지 않았습니다.

캐릭터 모션은 정적 이미지를 CSS로 흔드는 방식 대신, 게임의 원본 `char_001/002/003.zip`과 동일한 PuppetForge 커밋 `b5af06a3bcac73b8d639e7e760812d13ee19e475`의 idle 애니메이션 정점을 WebGL로 그립니다. SVG 지구본·체크·이전/다음 화살표도 `glyphs.ts`의 각진 기하를 웹용으로 옮겼습니다. 선형 아이콘은 24px 뷰박스에서 2.5px 선 두께를 사용하고, 도형으로 채운 화살표는 게임의 `back.svg` 형태를 따릅니다.

## 가독성

최소 12px, 일반 본문 15~16px, 인게임과 같은 실제 500/700/800 굵기를 사용합니다. CSS의 큰 숫자·제목에도 별도 세리프를 사용하지 않습니다. 언어 ko/en/ja, 화면 너비 360/375/390/768/1024/1440에서 실제 렌더링된 텍스트 크기와 폰트 스택, 가로 넘침을 확인합니다. 이미지에 포함된 인게임 UI 글자는 스크린샷이므로 CSS 크기 규칙의 대상이 아니며 클릭해 확대할 수 있습니다.
