# 홈페이지에서 커뮤니티·피드백·문의로 확장

외부 카페를 전제로 하지 않고 이 웹사이트를 공식 소식과 향후 커뮤니티의 진입점으로 유지합니다. 현재 구현된 것은 공지·출시 알림과 홈페이지입니다. 아직 자유 게시판이나 문의 접수를 받는 것처럼 표시하지 않습니다.

## 공통 기반

- `src/ui/icons.ts`: 게임 형태의 굵은 SVG.
- `src/ui/language-picker.ts`, `controls.css`: 커스텀 선택창·스크롤·입력·검증·팝업. 신규 게시판 필터와 문의 폼에서도 동일한 규칙을 적용합니다.
- `src/ui/feedback.ts`, `scroll.ts`, `motion.css`: 게임 기준 눌림, 화면 클릭, 기본 스크롤을 보존하는 가벼운 구간 진입 연출.
- `src/puppets.ts`: 원본 퍼펫의 실제 idle 재생. 화면 밖·비활성 탭·동작 줄이기 환경에서 정지/정적 대체. 게시판 목록에서는 캐릭터를 자동으로 여러 개 재생하지 않습니다.
- `AGENTS.md`: 향후 작업에서도 유지할 폰트 최소 크기·게임 톤·브라우저 UI·접근성·성능 규칙.

## 향후 별도 구현 범위

공개 공지와 이용자 게시물은 별도 모델로 두고 목록 API는 페이지네이션과 검색 범위를 제한합니다. 계정 연결 이후 쓰기·수정·삭제 소유권을 서버/RLS에서 확인하고, 신고·관리자 조치·작성 제한을 함께 구현합니다. 비공개 문의는 공개 게시판과 저장·읽기 권한을 분리하고, 개인정보 처리 및 답변 알림/수신 거부 정책을 정한 뒤 접수를 엽니다.

출시 알림 API는 문의 접수나 게시판 글쓰기 용도로 재사용하지 않습니다. Supabase 실제 연결 및 운영 정책이 확정된 뒤 DB 변경을 검토하고 end-to-end 검증해야 합니다.
